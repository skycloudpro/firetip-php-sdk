### Overview

The **Firetip PHP SDK v2.01** is engineered for secure, sovereign outreach and high-performance infrastructure control. Featuring **HMAC-SC01 cryptographic hardware validation**, the SDK ensures zero plaintext API keys are exposed while supporting custom domain bridging and direct lead ingestion.

---

### Requirements

* **PHP:** `^8.1` or higher
* **Extensions:** `ext-curl`, `ext-json`, `ext-hash`
* **Node Target:** `sc01` hardware validation layer enabled
